## Layout

From top to bottom, the main window has:

- **Title bar**: buttons for *New project*, *Open project* and *Save*, then *Undo* and *Redo*. The center shows the name of the active model. On the right are the theme switch (light or dark) and the window buttons.
- **Ribbon**: the tabs **File**, **Model**, **Results** and **Help**. Each tab shows a row of buttons below it.
- **Canvas**: the model, in edit mode or result mode, with a floating toolbar.
- **Status bar**: the mode, the number of boundary points, the factor of safety of the last analysis, the snap settings and the cursor coordinates.

The **Explorer** (the list of models) is on the left; in result mode the **result sidebar** is on the right. Each panel has a collapse button at the window edge of its header row. A collapsed panel is a narrow strip along the window edge with its name and a button that opens it again. Right-click the header row or the strip and choose *Move panel to the left* (or *right*) to move the panel to the other side of the window. Drag a panel's edge to resize it; dragging it well past its minimum width collapses it.

## The ribbon

| Tab | Buttons |
| --- | --- |
| **File** | New, Open, Import (DXF file, .gsz file, .stix file, .sli/.slim/.slmd file), Export (.gsz file, .stix file, .slim file), Save, Save as, Exit |
| **Model** | Boundaries (Exterior, Interior), Materials (Materials, Assign), Loads & support (Distributed loads, Line loads, Reinforcement), Water & parameters (Piezometric lines, Parameters), Analysis (Search limits, Custom surfaces, Options) |
| **Results** | Plots (Results plot, Sensitivity, Probabilistic), Display (Surfaces, Slices, FOS label, Center, Soil colors, Plastic zone and FE mesh with a finite element result, Sheet settings), Annotations (Text, Plot, Material table, Color bar, Reference line), Templates (Export template, Import template), Export (Export: PDF, with PNG and slice data in its menu) |
| **Help** | Resources (Documentation, Shortcuts, Examples, Benchmarks, About) |

Hover over a button to see its shortcut, if it has one. After an analysis the ribbon shows the **Results** tab; back in edit mode it shows the **Model** tab again.

## Dialog windows

Each button on the **Model** tab opens its own window. The windows are not modal: they stay open next to the main window, and a change in a window shows on the canvas at once (and the other way round). Clicking the button of a window that is already open brings it to the front. <Kbd>Esc</Kbd> closes a window; a value typed in a field is kept.

**Results plot**, **Sensitivity** and **Probabilistic** on the **Results** tab open windows of their own in the same way. A field's tooltip says what it is, its unit and its default; the **?** at a section heading opens this documentation at the part that explains the section.

A window is a table of objects you also see on the canvas, and opening it does not change what you can edit there. Opening *Exterior* selects the exterior boundary on the canvas; picking a row in a window selects that point on the canvas, and a point you select on the canvas is the selected row in the open window. Closing a window leaves the selection as it is.

## Editing on the canvas

Every object on the canvas can be selected at any time: the exterior boundary, material boundaries, water lines, distributed and line loads, reinforcement and piles, the search limits and custom surfaces.

- **Hover** over an object to highlight it; the pointer becomes a hand.
- **Click** an object to select it. Its handles appear in the accent color and the status bar names it, for example *Selected: Water line 1*. Only the selected object can be changed: dragging over an object that is not selected moves nothing (with the *Pan* tool on, it pans).
- **Drag a handle** of the selected object to move that point. It snaps to the grid and to nearby points, shows its coordinates while you drag, and counts as one change for undo. A drag starts only once the pointer has moved a few pixels, so a click never moves anything. A load, or a custom surface, can also be dragged by its body to move it whole (a circle by its center); the exterior and material boundaries are edited point by point.
- **Click a point** of the selected object to select that point. Repeated clicks at one spot go through all the objects there in turn; the status bar shows, for example, *Water line 1 (2 of 3 under the pointer)*. <Kbd>Esc</Kbd> or a click on empty canvas clears the selection.
- The **arrow keys** move the selected point by one snap step (with <Kbd>Shift</Kbd> by ten), <Kbd>Delete</Kbd> removes it where a point can be removed, and a **double-click** on a point opens a small editor for its exact x and y.
- **Right-click** an object for its menu: *Add point* on a line, *Delete point* at a point, and *Lock* or *Unlock*. Right-click empty canvas for *Assign material…* (the region there), *Lock all* by type and *Unlock all*.

A **locked** object can still be selected, to read its coordinates, but its handles are gray with a padlock and it cannot be dragged, nudged or have points deleted on the canvas; the pointer shows *Locked · right-click to unlock*. Models imported from another program or from a DXF drawing start with the exterior and material boundaries locked, and the status bar shows *Geometry is locked (imported) · Unlock*. Locks are saved with each model, and locking or unlocking counts as one change for undo.

## Edit mode and result mode

The canvas has two modes, switched with **Edit** and **Results** on the floating toolbar:

- **Edit mode** shows the model with its boundaries, materials, water lines, loads, reinforcement and search limits. This is where you build and change the model.
- **Result mode** shows a print sheet with the analyzed model, the critical slip surface and the annotations. It becomes available after an analysis. See [Results](/docs/results).

**▶ Run** on the floating toolbar runs the analysis of the active model and switches to result mode. See [Running the analysis](/docs/analysis#running-the-analysis).

## The floating toolbar

The toolbar on the canvas holds the mode buttons, **▶ Run** (with *Run all*, *Clear results* and *Clear all results* in its menu), *Undo* and *Redo*, and the zoom tools: *Zoom out*, a zoom percentage, *Zoom in*, *Zoom box*, *Pan* and *Fit to screen*. It fades when the pointer is not over it.

## Models and projects

A project holds one or more **models**, listed in the Explorer under *Models*. Each model is a complete analysis with its own geometry, materials, options and result.

- Click a model to make it active; its row is highlighted. A model that has a result opens in result mode.
- The dot before each model shows its run state: green analyzed, blue running, red failed, hollow gray not analyzed.
- Double-click a model to rename it.
- Drag models to reorder them.
- <Kbd>Ctrl</Kbd>+click or <Kbd>Shift</Kbd>+click to select several models; right-click them for *Delete selected*.
- Right-click for *Model properties…*, *Rename*, *Duplicate* and *Delete*.

*Duplicate* is the way to try a variant of a model, for example with a different water level, and compare the results. *File › Import* also adds models: one from a DXF file, and one per analysis from a .gsz, .stix, .sli, .slim or .slmd file. A window then lists what was imported and what did not carry over, with a **Copy** button; the notes stay with each model under *Model properties…*. An import cannot be undone: delete the imported models to remove them. *File › Export* writes the active model as a .gsz, .stix or .slim file; its window lists what the format does not carry.

**Model properties…** opens the project information of the model: title, subtitle, client, project number, revision, date, author, checker and notes, and for an imported model the import notes (read-only). Text annotations on the result sheet can show these fields (see [Reporting](/docs/reporting)).

## Undo and redo

<Kbd>Ctrl</Kbd>+<Kbd>Z</Kbd> undoes the last change, <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Z</Kbd> or <Kbd>Ctrl</Kbd>+<Kbd>Y</Kbd> redoes it. There is one history, of the last 50 changes to the active model. Dragging a point counts as one change. The history is cleared when you switch models or open a project.

## Units

cSlope works in SI units only: meters, kN, kPa, kN/m³ and degrees. Forces are per meter run of the slope unless stated otherwise.
