| [A layered slope](/docs/tutorials/layered) | Interior boundaries, several materials, and assigning them to regions |
| [An embankment dam](/docs/tutorials/dam) | A zoned section that fails to the left, and the Morgenstern–Price λ plot |
| [Reinforcing a slope with soil nails](/docs/tutorials/soil-nails) | Adding reinforcement and reading the force in each element |
| [A design check with partial factors](/docs/tutorials/partial-factors) | Design values and the over-design factor |
| [Reporting](/docs/tutorials/reporting) | The result sheet, annotations, templates and export |
| [Sensitivity and probability](/docs/tutorials/probabilistic) | Sensitivity sweeps, the Taylor series and the probability of failure |
