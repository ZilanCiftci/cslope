## Keyboard

| Keys | Action |
| --- | --- |
| <Kbd>Ctrl</Kbd>+<Kbd>N</Kbd> | New project |
| <Kbd>Ctrl</Kbd>+<Kbd>O</Kbd> | Open project… |
| <Kbd>Ctrl</Kbd>+<Kbd>S</Kbd> | Save |
| <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>S</Kbd> | Save as… |
| <Kbd>Ctrl</Kbd>+<Kbd>Z</Kbd> | Undo |
| <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Z</Kbd> or <Kbd>Ctrl</Kbd>+<Kbd>Y</Kbd> | Redo |
| <Kbd>Delete</Kbd> / <Kbd>Backspace</Kbd> | Delete the selected point (edit mode, where a point can be removed and the object is not locked) or the selected annotations (result mode) |
| Arrow keys | Edit mode: move the selected point by one snap step, with <Kbd>Shift</Kbd> by ten. Result mode: move the selected annotations; with <Kbd>Shift</Kbd> in smaller steps |
| <Kbd>Alt</Kbd>+<Kbd>↑</Kbd> / <Kbd>Alt</Kbd>+<Kbd>↓</Kbd> | In the result sidebar's [Layers](/docs/reporting#layers) list: draw the focused layer one above or below (the arrow keys alone move the focus, <Kbd>Delete</Kbd> removes the layer or turns it off). On a drawing's row in the Models panel: draw the [drawing](/docs/drawings#the-drawings-of-a-model) one above or below the next (<Kbd>Delete</Kbd> removes it from the model) |
| <Kbd>F5</Kbd> or <Kbd>Ctrl</Kbd>+<Kbd>Enter</Kbd> | Run the analysis (not while typing in a field) |
| <Kbd>Esc</Kbd> | Close a menu or a dialog window (a value typed in a field is kept); on the canvas, clear the selection or stop picking lines |

## Mouse, edit mode

| Action | Effect |
| --- | --- |
| Click an object | Select it: its handles appear |
| Click a point of the selected object | Select the point |
| Click again at the same spot | Select the next object under the pointer |
| Click empty canvas | Clear the selection |
| Drag a handle of the selected object | Move it (snaps to the grid and to nearby points) |
| Drag a load or a custom surface (selected) | Move it whole |
| Double-click a point of the selected object | Type its exact coordinates |
| Right-click an edge | **Add point**, **Lock** / **Unlock** the object (for example **Lock exterior boundary**) |
| Right-click a point | **Delete point**, **Lock** / **Unlock** the object |
| Right-click empty canvas | **Assign material…**, **Lock all**, **Unlock all** |
| Double-click a region | Choose its material |
| Click a line of a drawing, while picking lines | Pick it; <Kbd>Shift</Kbd>+click adds a line or removes a picked one; drag a window to pick the lines inside it |
| <Kbd>Ctrl</Kbd>+wheel | Zoom at the cursor |
| Wheel, or middle-button drag | Pan |

Only the selected object can be dragged: a drag over another object moves nothing. A locked object can be selected but not changed. See [Editing on the canvas](/docs/interface#editing-on-the-canvas).

## Mouse, result mode

| Action | Effect |
| --- | --- |
| Click an annotation | Select it; <Kbd>Ctrl</Kbd> or <Kbd>Shift</Kbd>+click adds to the selection |
| Drag an annotation | Move it (a reference line once it is selected) |
| Right-click with several selected | Align them |
| Click the empty sheet | Select the paper, to set its size and extents |
| <Kbd>Ctrl</Kbd>+wheel | Zoom the sheet |
| Middle-button drag | Move the sheet |
