## Keyboard

| Keys | Action |
| --- | --- |
| <Kbd>Ctrl</Kbd>+<Kbd>N</Kbd> | New project |
| <Kbd>Ctrl</Kbd>+<Kbd>O</Kbd> | Open project |
| <Kbd>Ctrl</Kbd>+<Kbd>S</Kbd> | Save |
| <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>S</Kbd> | Save as |
| <Kbd>Ctrl</Kbd>+<Kbd>Z</Kbd> | Undo |
| <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>Z</Kbd> or <Kbd>Ctrl</Kbd>+<Kbd>Y</Kbd> | Redo |
| <Kbd>Delete</Kbd> / <Kbd>Backspace</Kbd> | Delete the selected exterior boundary point (edit mode, with *Exterior* open and more than 3 points) or the selected annotations (result mode) |
| Arrow keys | Move the selected annotations; with <Kbd>Shift</Kbd> in smaller steps |
| <Kbd>F5</Kbd> or <Kbd>Ctrl</Kbd>+<Kbd>Enter</Kbd> | Run the analysis (not while typing in a field) |
| <Kbd>Esc</Kbd> | Close a menu or a dialog window (a value typed in a field is kept) |

## Mouse, edit mode

| Action | Effect |
| --- | --- |
| Drag a point | Move it (snaps to the grid and to nearby points) |
| Click a point | Select it |
| Right-click an edge | **Add Point** |
| Right-click a point | **Delete Point** |
| Click a region (with *Assign* open) | Choose its material |
| <Kbd>Ctrl</Kbd>+wheel | Zoom at the cursor |
| Wheel, or middle-button drag | Pan |

What you can drag depends on the open dialog window: boundary points with *Exterior* or *Interior*, water-line points with *Piezometric Lines*, load positions with *UDL* or *Line loads*, and the search ranges with *Search limits*.

## Mouse, result mode

| Action | Effect |
| --- | --- |
| Click an annotation | Select it; <Kbd>Ctrl</Kbd> or <Kbd>Shift</Kbd>+click adds to the selection |
| Drag an annotation | Move it |
| Right-click with several selected | Align them |
| Click the empty sheet | Select the paper, to set its size and extents |
| <Kbd>Ctrl</Kbd>+wheel | Zoom the sheet |
| Middle-button drag | Move the sheet |
